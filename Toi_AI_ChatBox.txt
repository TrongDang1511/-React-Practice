Thủ thuật sử dụng -1 làm cờ hiệu (Flag)
Tại sao lại là -1? Trong JavaScript, chỉ số (index) của mảng luôn bắt đầu từ 0, 1, 2.... Không bao giờ có phần tử nào nằm ở vị trí -1.
Khi ta đặt state mặc định là -1, biểu thức so sánh isExpanded = (index === expandedIndex) sẽ luôn luôn trả về false cho tất cả các phần tử (vì 0, 1, 2 không thể bằng -1). Nhờ đó, tất cả các thẻ div chứa nội dung đều bị ẩn đi lúc khởi tạo.

Logic Bật/Tắt (Toggle Logic)
Thay vì chỉ nhắm mắt gán bừa giá trị mới khi click, ta cần kiểm tra: "Cái thẻ mà người dùng vừa click có phải là cái thẻ đang mở hay không?" (expandedIndex === nextIndex).
Nếu ĐÚNG: Nghĩa là họ muốn ĐÓNG nó lại -> Đưa state về trạng thái "không có ai mở cả" (-1).
Nếu SAI: Nghĩa là họ muốn MỞ một thẻ mới -> Gán state bằng chính cái nextIndex đó.

JavaScript
import { useState } from 'react';
import { GoChevronDown, GoChevronLeft } from 'react-icons/go';

function Accordion({ items }) {
// 1. Đổi giá trị mặc định thành -1 để đóng tất cả khi mới load trang
const [expandedIndex, setExpandedIndex] = useState(-1);

const handleClick = (nextIndex) => {
// 2. Logic kiểm tra: Nếu click vào thẻ đang mở thì đóng nó lại (gán -1)
if (expandedIndex === nextIndex) {
setExpandedIndex(-1);
} else {
// Nếu click vào thẻ khác, thì mở thẻ đó ra
setExpandedIndex(nextIndex);
}
};

const renderedItems = items.map((item, index) => {
const isExpanded = index === expandedIndex;

const icon = <span className="text-2xl">{isExpanded ? <GoChevronDown/> : <GoChevronLeft/>}</span>;

return (
  <div key={item.id} className="border-x border-t rounded">
    <div 
      className="flex justify-between p-3 bg-gray-50 border-b items-center cursor-pointer"
      onClick={() => handleClick(index)}
    >
      {item.label}
      {icon}
    </div>
    {isExpanded && <div className="border-b p-5">{item.content}</div>}
  </div>
);
});

return (

{renderedItems}

);
}

export default Accordion;

Thuộc tính label là đoạn text mà ta sẽ hiển thị trong dropdown cho người dùng xem.
Thuộc tính value là một chuỗi ngắn (hoặc số) mang ý nghĩa đặc biệt bên trong code của chúng ta.

Bằng cách này, ta có một nguồn thông tin để tùy chỉnh giao diện (label), và một nguồn thông tin thứ hai dùng để xử lý logic (value).
Sau này, để biết người dùng đã chọn gì, ta chỉ cần gọi selected.value. Ví dụ: if (selected.value === 'spicy') { makeFoodSpicy(); }.

Đó là ý tưởng cốt lõi. Bất cứ khi nào sử dụng dropdown, ta sẽ truyền xuống một prop options là một mảng các object. label là thứ người dùng thấy, value là thứ lập trình viên dùng để xử lý logic.

Tiêu chuẩn ngành: Dùng cấu trúc { label, value }.
label (Nhãn hiển thị): Phục vụ người dùng (UI). Có thể dài dòng, chứa dấu cách, thay đổi thoải mái theo yêu cầu giao diện.
value (Giá trị lõi): Phục vụ hệ thống (Logic). Thường là chữ thường, viết liền (camelCase/kebab-case) hoặc ID, không bao giờ thay đổi bất chấp giao diện có bị sửa lại bao nhiêu lần.

# Section 12: Practicing Props and State Design (Bài 197 - 207)

## 📌 Tổng quan chủ đề
Thiết kế và xây dựng **Dropdown Component** nâng cao trong React: từ thiết kế Props, tư duy thiết kế State, đến việc biến Dropdown thành **Controlled Component** tuân theo chuẩn convention của cộng đồng.

---

## 1. Lesson 197: Component Overview (Tổng quan về Dropdown)
* **Mục tiêu**: Xây dựng một Dropdown component tái sử dụng được.
* **Hành vi người dùng**:
  1. Ban đầu hiển thị một ô chọn (box) chứa chữ mặc định `Select...` kèm icon mũi tên.
  2. Khi người dùng click vào ô chọn, mở một menu chứa các tùy chọn (options) bên dưới.
  3. Khi người dùng click vào một option (ví dụ: `Red`), menu đóng lại và ô chọn cập nhật chữ thành `Red`.
* **Thách thức**: Thiết kế Props linh hoạt và quản lý State chính xác.

## 2. Lesson 198: Designing the Props (Thiết kế cấu trúc Props)

### ❌ Cách 1: Mảng các chuỗi (Array of Strings) - KHÔNG NÊN DÙNG
```javascript
// Dữ liệu mảng chỉ chứa các chuỗi thuần túy
const options = ['I want mild', 'Spicy', 'Give Me Extra Spicy'];

// KHỦNG HOẢNG: Khi cần kiểm tra tùy chọn người dùng đã chọn:
if (selected === 'Give Me Extra Spicy') { 
    // Rất dễ sai chính tả (typo). 
    // Nếu UI muốn đổi chữ thành 'Extra Spicy' -> Toàn bộ logic code kiểm tra ở đây bị gãy!
}
```

### ✅ Cách 2: Mảng các Object (Array of Objects) - CHUẨN BEST PRACTICE
```javascript
// Mảng chứa các Object, tách biệt giao diện (label) và mã dữ liệu (value)
const options = [
  { label: 'Mild', value: 'mild' },            // label: Người dùng nhìn thấy trên màn hình
  { label: 'Spicy', value: 'spicy' },          // value: Mã định danh dùng cho logic code / API
  { label: 'Extra Spicy', value: 'extra_spicy' }
];

// KHI KIỂM TRA LOGIC: An toàn, ngắn gọn, không lo đổi chữ giao diện
if (selected.value === 'spicy') {
    // Làm món ăn cay...
}
```

## 4. Lesson 200 & 201: State Design Process & Implementation (Đóng/Mở Menu)

### Quy trình thiết kế State cho tính năng Đóng/Mở:
1. **Sự kiện (Event)**: Người dùng click vào khung header của Dropdown.
2. **State cần thiết**: `isOpen` (kiểu boolean: `true` là đang mở, `false` là đang đóng).
3. **Cập nhật State**: Đảo ngược giá trị `isOpen` khi click (`setIsOpen(!isOpen)`).

### Code triển khai `Dropdown.jsx` (Bài 201):
```javascript
import { useState } from 'react';

function Dropdown({ options }) {
    // State quản lý trạng thái ẩn/hiện menu (mặc định false = đóng)
    const [isOpen, setIsOpen] = useState(false);

    // Handler xử lý khi click vào ô hiển thị header
    const handleClick = () => {
        // Đảo ngược trạng thái: nếu đang đóng -> mở, đang mở -> đóng
        setIsOpen(!isOpen);
    };

    // Duyệt qua danh sách options được truyền từ App xuống để tạo các thẻ <div>
    const renderedOptions = options.map((option) => {
        return (
            <div key={option.value}>
                {option.label}
            </div>
        );
    });

    return (
        <div>
            {/* Click vào ô này để bật/tắt hiển thị menu */}
            <div onClick={handleClick}>Select...</div>

            {/* Điều kiện ngắn (Short-circuit): Nếu isOpen là true thì mới render danh sách renderedOptions */}
            {isOpen && <div>{renderedOptions}</div>}
        </div>
    );
}
```

## 5. Lesson 202: Event Handlers in Maps (Xử lý sự kiện trong vòng lặp `.map()`)

Khi click vào từng option trong danh sách, ta cần truyền thông tin `option` được click vào hàm xử lý:
```javascript
// Hàm xử lý khi người dùng chọn 1 phần tử
const handleOptionClick = (option) => {
    // 1. Đóng menu ngay sau khi chọn xong
    setIsOpen(false);
    // 2. In thông tin option ra console kiểm tra
    console.log(option);
};

const renderedOptions = options.map((option) => {
    return (
        // LƯU Ý QUAN TRỌNG:
        // Phải bọc trong arrow function () => handleOptionClick(option)
        // để HOÃN lại việc gọi hàm, chỉ khi NGHƯỜI DÙNG CLICK mới chạy hàm và truyền đúng option được chọn!
        <div onClick={() => handleOptionClick(option)} key={option.value}>
            {option.label}
        </div>
    );
});
```

## 6. Lesson 203 & 204: Dropdown as a Controlled Component (Tư duy Controlled Component)

### ❓ Vấn đề nếu đặt State `selection` trong `Dropdown.jsx`:
Nếu `Dropdown` tự lưu trữ `selection` bên trong nó, component cha `App` sẽ **KHÔNG THỂ** biết người dùng đang chọn màu gì để thực hiện các thao tác tiếp theo (lưu vào database, lọc danh sách sản phẩm, v.v.).

### 💡 Giải pháp: Biến Dropdown thành Controlled Component
Đưa State `selection` lên component cha (`App.jsx`), truyền dữ liệu xuống qua Props:
* `value` (hoặc `selection`): Tùy chọn đang được chọn hiện tại.
* `onChange` (hoặc `onSelect`): Callback function để Dropdown thông báo cho `App` biết khi người dùng click chọn 1 item mới.

---

### Code triển khai hoàn chỉnh (Bài 204):

#### 📄 Tại `App.jsx` (Component Cha - Nơi nắm giữ State chính):
```javascript
import { useState } from 'react';
import Dropdown from './components/Dropdown';

function App() {
    // State lưu giữ lựa chọn hiện tại của người dùng (khởi tạo là null = chưa chọn gì)
    const [selection, setSelection] = useState(null);

    // Callback handler nhận option từ Dropdown gửi lên và cập nhật state selection
    const handleSelect = (option) => {
        setSelection(option);
    };

    // Mảng dữ liệu danh sách tùy chọn
    const options = [
        { label: 'Red', value: 'red' },
        { label: 'Green', value: 'green' },
        { label: 'Blue', value: 'blue' }
    ];

    return (
        <div>
            {/* Truyền dữ liệu options, giá trị đang chọn value, và hàm lắng nghe onChange xuống Dropdown */}
            <Dropdown options={options} value={selection} onChange={handleSelect} />
        </div>
    );
}
```

#### 📄 Tại `Dropdown.jsx` (Component Con - Controlled Component):
```javascript
import { useState } from 'react';

// Nhận 3 props: options (danh sách), value (giá trị hiện tại từ App), onChange (hàm báo về App)
function Dropdown({ options, value, onChange }) {
    // State quản lý việc Đóng/Mở menu nội bộ trong Dropdown
    const [isOpen, setIsOpen] = useState(false);

    // Khi click vào ô header -> Đảo ngược trạng thái mở/đóng
    const handleClick = () => {
        setIsOpen(!isOpen);
    };

    // Khi click vào 1 option trong danh sách
    const handleOptionClick = (option) => {
        // 1. Đóng menu Dropdown
        setIsOpen(false);
        // 2. GỌI HÀM CALLBACK ONCHANGE TRUYỀN TỪ APP ĐỂ BÁO OPTION MỚI VỀ CHO APP
        onChange(option);
    };

    // Render danh sách các thẻ div cho từng option
    const renderedOptions = options.map((option) => {
        return (
            // Bắt sự kiện click vào từng option và gọi handleOptionClick
            <div onClick={() => handleOptionClick(option)} key={option.value}>
                {option.label}
            </div>
        );
    });

    return (
        <div>
            {/* Hiển thị nhãn đang chọn (nếu chưa chọn thì hiển thị 'Select...') */}
            <div onClick={handleClick}>
                {value?.label || 'Select...'}
            </div>
            {/* Render danh sách tùy chọn nếu isOpen là true */}
            {isOpen && <div>{renderedOptions}</div>}
        </div>
    );
}
```

## 7. Lesson 205: Existence Check Helper (`value?.label || 'Select...'`)
* Ban đầu, State `selection` ở `App.jsx` khởi tạo là `null`.
* Nếu viết `{value.label}` khi `value` là `null` -> Sẽ bị văng lỗi runtime: `TypeError: Cannot read properties of null (reading 'label')`.
* **Giải pháp chi tiết**:
```javascript
// Dùng Optional Chaining (?.): Nếu value khác null/undefined mới lấy label, ngược lại trả về undefined
// Dùng Toán tử || (Logical OR): Nếu vế trái là undefined/null, lấy giá trị mặc định 'Select...' bên phải
{value?.label || 'Select...'}
```

## 8. Lesson 206 & 207: Community Convention with Props Names (Quy ước đặt tên Props trong cộng đồng React)

* **Thẻ HTML Form mặc định (`<input>`, `<select>`)**: Đều dùng prop `value` để truyền giá trị và `onChange` để bắt sự kiện thay đổi.
* **Custom Component do lập trình viên tự viết (`<Dropdown>`)**: Cũng nên sử dụng tên props là `value` và `onChange` để tuân theo convention toàn ngành.
* **Lợi ích**: Giúp người khác (hoặc chính bạn trong tương lai) khi dùng component `<Dropdown>` sẽ biết ngay cách truyền dữ liệu mà không cần phải đọc lại code bên trong.

---

## 📝 Tóm tắt cốt lõi cần nhớ:
1. `options` nên là mảng các object `{ label, value }`.
2. Dùng arrow function `() => handleOptionClick(option)` để hoãn thực thi và truyền tham số trong vòng lặp `.map()`.
3. Dropdown phải là **Controlled Component**: App nắm giữ State `selection`, Dropdown gọi `onChange(option)` để báo kết quả.
4. Dùng `value?.label || 'Select...'` để tránh crash app khi giá trị ban đầu là `null`.

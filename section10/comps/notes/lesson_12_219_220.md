Sử dụng **`useRef` Hook** để lấy tham chiếu DOM element thực tế trong React và hoàn thiện tính năng **Click Outside** (Tự động đóng Dropdown khi click ra ngoài).

---

## 1. Lesson 219: `useRef` in Action (Khái niệm & Cách dùng `useRef`)

### 🧠 Lý thuyết cốt lõi:
- **`useRef` là gì?**: Là một React Hook giúp component giữ một tham chiếu (pointer) trực tiếp đến một thẻ DOM HTML thực tế được tạo ra trên trình duyệt.
- **Tại sao cần `useRef`?**: Nếu dùng `document.querySelector`, khi trên trang có 2-3 Dropdown nó sẽ chọn nhầm giữa các Dropdown. `useRef` giúp mỗi Dropdown quản lý độc lập thẻ DOM của riêng mình.
- **Đặc điểm quan trọng**: `useRef()` trả về một **Object** chứa duy nhất thuộc tính `.current`:
  `divEl.current` -> Mới là thẻ HTML thực tế trên DOM (`<div>...</div>`).

---

## 2. Lesson 220: Checking Click Location & Finishing Dropdown (Hoàn thiện tính năng)

### 🧠 Logic kiểm tra vị trí Click:
Dùng hàm thuần của DOM: `divEl.current.contains(event.target)`
- **`event.target`**: Thẻ HTML thực tế mà người dùng vừa click vào.
- **`contains()`**: Kiểm tra xem `event.target` có nằm bên trong `divEl.current` (Dropdown) hay không.
  - Nếu `divEl.current.contains(event.target)` là `true` -> Click **BÊN TRONG** Dropdown -> Không làm gì cả.
  - Nếu là `false` (`!divEl.current.contains(event.target)`) -> Click **BÊN NGOÀI** Dropdown -> Gọi `setIsOpen(false)` để đóng menu.

### 🛡️ Kỹ thuật phòng lỗi `!divEl.current`:
Nếu thẻ `div` chưa kịp render hoặc bị ẩn, `divEl.current` sẽ là `null`. Phải check an toàn ở đầu hàm: `if (!divEl.current) return;` để tránh văng lỗi crash app.

### 📄 Mã nguồn đầy đủ hoàn chỉnh của `src/components/Dropdown.jsx`:

```javascript
// Bước 1: Import thêm useRef từ 'react'
import { useState, useEffect, useRef } from 'react';
import { GoChevronDown } from 'react-icons/go';
import Panel from './Panel';

function Dropdown({ options, value, onChange }) {
    const [isOpen, setIsOpen] = useState(false);

    // Bước 2: Tạo reference để trỏ đến thẻ div ngoài cùng của Dropdown
    const divEl = useRef();

    useEffect(() => {
        const handler = (event) => {
            // Kiểm tra an toàn: Nếu ref chưa trỏ tới thẻ HTML nào -> Thoát sớm
            if (!divEl.current) {
                return;
            }

            // Kiểm tra: Nếu vị trí click KHÔNG nằm bên trong thẻ Dropdown
            if (!divEl.current.contains(event.target)) {
                // Đóng menu Dropdown lại
                setIsOpen(false);
            }
        };

        // Đăng ký lắng nghe sự kiện click ở Capture phase (true)
        document.addEventListener('click', handler, true);

        // Cleanup: Hủy lắng nghe khi unmount
        return () => {
            document.removeEventListener('click', handler, true);
        };
    }, []);

    const handleClick = () => {
        setIsOpen(!isOpen);
    };

    const handleOptionClick = (option) => {
        setIsOpen(false);
        onChange(option);
    };

    const renderedOptions = options.map((option) => {
        return (
            <div
                className="hover:bg-sky-100 rounded cursor-pointer p-1"
                onClick={() => handleOptionClick(option)}
                key={option.value}
            >
                {option.label}
            </div>
        );
    });

    return (
        // Bước 4: Gắn ref={divEl} vào thẻ div bao ngoài cùng
        <div ref={divEl} className="w-48 relative">
            <Panel
                className="flex justify-between items-center cursor-pointer"
                onClick={handleClick}
            >
                {value?.label || 'Select...'}
                <GoChevronDown className="text-lg" />
            </Panel>

            {isOpen && (
                <Panel className="absolute top-full">
                    {renderedOptions}
                </Panel>
            )}
        </div>
    );
}

export default Dropdown;
```

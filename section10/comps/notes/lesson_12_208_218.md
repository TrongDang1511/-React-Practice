## 1. Lesson 208: Adding Styling (Thêm Tailwind CSS & Icon - Phiên bản sơ khai trước khi tách Panel)

### 📄 Mã nguồn hoàn chỉnh `src/components/Dropdown.jsx` ở Lesson 208:
```javascript
import { useState } from 'react';
// Import icon mũi tên chỉ xuống từ react-icons
import { GoChevronDown } from 'react-icons/go';

function Dropdown({ options, value, onChange }) {
    const [isOpen, setIsOpen] = useState(false);

    const handleClick = () => {
        setIsOpen(!isOpen);
    };

    const handleOptionClick = (option) => {
        setIsOpen(false);
        onChange(option);
    };

    // Render từng dòng option kèm hiệu ứng hover chuột và bo góc
    const renderedOptions = options.map((option) => {
        return (
            <div 
                className="hover:bg-sky-100 rounded cursor-pointer p-1" 
                onClick={() => handleOptionClick(option)} 
                key={option.value}
            >
                {option.label}
            </div>
        );
    });

    return (
        // Khung ngoài: Chiều rộng cố định w-48 (12rem) và position relative làm điểm tựa cho menu con
        <div className="w-48 relative">
            {/* Header: Căn giữa hai bên (justify-between), viền border, bo góc, nền trắng, đổ bóng shadow */}
            <div 
                className="flex justify-between items-center cursor-pointer border rounded p-3 shadow bg-white w-full"
                onClick={handleClick}
            >
                {value?.label || 'Select...'}
                <GoChevronDown className="text-lg" />
            </div>

            {/* Menu Options: Vị trí absolute bám sát đáy header (top-full), cũng có border, rounded, shadow, bg-white */}
            {isOpen && (
                <div className="absolute top-full border rounded p-3 shadow bg-white w-full">
                    {renderedOptions}
                </div>
            )}
        </div>
    );
}

export default Dropdown;
```

> **Quan sát ở Bài 208**: Bạn sẽ thấy chuỗi class `border rounded p-3 shadow bg-white w-full` xuất hiện giống hệt nhau ở cả 2 thẻ `<div>`. Đây chính là lý do Stephen Grider dẫn sang Bài 209 để tách thành component `Panel.jsx`.

## 2. Lesson 209 & 210: Creating the Reusable Panel (Tạo Component Panel tái sử dụng)

### 💡 Vấn đề: Trùng lặp Class CSS
Cả khung Header và khung Menu Options đều dùng chung một bộ class:
`border rounded p-3 shadow bg-white w-full`
-> Cần tách ra thành component `Panel.jsx` để tái sử dụng ở mọi nơi.

### 📄 Code triển khai: `src/components/Panel.jsx`
```javascript
// Import thư viện classnames để gộp nhiều chuỗi class linh hoạt
import classNames from 'classnames';

// Nhận: children (nội dung bên trong), className (class bổ sung từ ngoài), ...rest (các sự kiện như onClick, onBlur...)
function Panel({ children, className, ...rest }) {
    // Gộp class mặc định của Panel với bất kỳ class nào được truyền từ component cha vào
    const finalClassNames = classNames(
        'border rounded p-3 shadow bg-white w-full', // Class giao diện mặc định
        className                                    // Class tùy biến thêm (ví dụ: flex, absolute...)
    );

    return (
        // Rải ...rest để nhận tất cả các props/sự kiện (onClick, id, style...) gắn vào thẻ div thực tế
        <div {...rest} className={finalClassNames}>
            {children}
        </div>
    );
}

export default Panel;
```

## 3. Lesson 211: A Challenging Extra Feature (Thử thách Click Outside)

### ❓ Vấn đề thực tế:
* Nếu người dùng mở Dropdown 1, sau đó click ra ngoài khoảng trắng hoặc click vào Dropdown 2, Dropdown 1 **vẫn mở nguyên**.
* Các event handler `onClick` trong React chỉ lắng nghe được các phần tử **bên trong** chính component đó tạo ra. Nó không thể bắt được sự kiện khi người dùng click vào các thẻ HTML nằm **bên ngoài** Dropdown.

## 4. Lesson 212: Document-Wide Click Handlers (Lắng nghe sự kiện toàn trang)

Để bắt được click ở bất kỳ đâu trên màn hình, ta phải dùng DOM API thuần của trình duyệt:
```javascript
// Đăng ký lắng nghe sự kiện click trên toàn bộ đối tượng window/document
document.addEventListener('click', (event) => {
    // event.target: Chính là thẻ HTML thực tế mà người dùng vừa click vào
    console.log(event.target);
});
```

## 5. Lesson 213, 214 & 215: Event Capture vs Bubbling (Cơ chế lan truyền sự kiện)

### 3 Giai đoạn khi một sự kiện xảy ra trên trình duyệt:
```
           [ window / document ]
                │           ▲
Phase 1: CAPTURE│           │ Phase 3: BUBBLE
 (Đi từ Gốc     │           │  (Nổi từ Đích
  xuống Đích)   ▼           │   lên Gốc)
            [ <div> Dropdown ]
                │           │
                ▼           │
             [ <button> Target ]  <─── Phase 2: TARGET
```

1. **Phase 1: Capture Phase (Bắt sự kiện từ trên xuống)**:
   * Sự kiện đi từ đỉnh cao nhất: `window` -> `document` -> `body` -> các thẻ cha -> thẻ đích (`target`).
2. **Phase 2: Target Phase**:
   * Sự kiện kích hoạt tại chính thẻ bị click.
3. **Phase 3: Bubbling Phase (Nổi bọt từ dưới lên)**:
   * Sự kiện nổi ngược lại từ thẻ đích -> các thẻ cha -> `body` -> `document` -> `window`.
   * **Mặc định trong React và JS**: Mọi sự kiện `onClick` hay `addEventListener` đều chạy ở **Phase 3 (Bubbling)**.

### 🔥 Tại sao PHẢI dùng Capture Phase cho Dropdown? (Lesson 215)
* Khi click vào 1 option, React cập nhật state `setIsOpen(false)` và lập tức xóa (unmount) menu options khỏi DOM.
* Nếu lắng nghe ở Bubbling Phase, đến khi sự kiện nổi lên tới `document`, thì thẻ bị click đã bị React gỡ khỏi DOM rồi -> Kiểm tra `contains(event.target)` sẽ cho kết quả sai lệch!
* **Giải pháp**: Truyền đối số thứ ba `true` vào `addEventListener` để bắt ngay ở **Capture Phase** trước khi React kịp gỡ phần tử:
```javascript
document.addEventListener('click', handler, true); // true = Capture Phase
```

## 6. Lesson 216 & 217: `useEffect` & Cơ chế Cleanup Function (Vị trí đặt code chuẩn)

### 📄 Mã nguồn đầy đủ `src/components/Dropdown.jsx` (Gắn `useEffect` trực tiếp bên trong Component):
```javascript
// 1. Import thêm useEffect từ 'react' cùng với useState
import { useState, useEffect } from 'react';
import { GoChevronDown } from 'react-icons/go';
import Panel from './Panel';

function Dropdown({ options, value, onChange }) {
    const [isOpen, setIsOpen] = useState(false);

    // 2. Đặt useEffect NGAY BÊN TRONG component Dropdown (sau các khai báo state)
    useEffect(() => {
        // Khai báo hàm handler bắt sự kiện click
        const handler = (event) => {
            // In ra phần tử vừa bị click trên màn hình để kiểm tra
            console.log(event.target);
        };

        // Đăng ký sự kiện click lên document ở Capture phase (tham số thứ ba = true)
        document.addEventListener('click', handler, true);

        // CLEANUP FUNCTION: Tự động chạy để gỡ bỏ sự kiện khi Dropdown bị unmount
        return () => {
            document.removeEventListener('click', handler, true);
        };
    }, []); // Mảng rỗng [] -> Đảm bảo useEffect chỉ đăng ký 1 lần duy nhất khi Dropdown xuất hiện (mount)

    const handleClick = () => {
        setIsOpen(!isOpen);
    };

    const handleOptionClick = (option) => {
        setIsOpen(false);
        onChange(option);
    };

    const renderedOptions = options.map((option) => {
        return (
            <div
                className="hover:bg-sky-100 rounded cursor-pointer p-1"
                onClick={() => handleOptionClick(option)}
                key={option.value}
            >
                {option.label}
            </div>
        );
    });

    return (
        <div className="w-48 relative">
            <Panel
                className="flex justify-between items-center cursor-pointer"
                onClick={handleClick}
            >
                {value?.label || 'Select...'}
                <GoChevronDown className="text-lg" />
            </Panel>

            {isOpen && (
                <Panel className="absolute top-full">
                    {renderedOptions}
                </Panel>
            )}
        </div>
    );
}

export default Dropdown;
```

## 7. Lesson 218: Issues with Element References (Tại sao không dùng `querySelector`?)
* Nếu dùng `document.querySelector('.dropdown')`, khi trên màn hình có từ **2 Dropdown trở lên**, hàm sẽ luôn luôn chỉ chọn trúng Dropdown đầu tiên -> Gây xung đột và lỗi logic.
* **Giải pháp**: React cung cấp Hook chuyên dụng `useRef` để giữ tham chiếu trực tiếp đến đúng phần tử DOM của từng instance riêng biệt (sẽ học và triển khai chi tiết ở bài 219 - 220).
